# Gavatrakot — логотип и баннеры (черновики)

Черновики по брифу: по одному варианту в трёх стилевых направлениях.
Интерактивный холст со всеми артбордами: https://claude.ai/code/artifact/d7212b67-0b42-4b85-b9df-38edae89f500

## Направления

| | 1 · Минимализм | 2 · Тёплый премиум | 3 · Энергичный |
|---|---|---|---|
| Знак | «Пересечение»: заполненный круг (ты) + контурный (знакомые) | «Место за столом»: круг из точек, одна присоединяется снаружи | «Искра»: семь лучей разной длины из одного центра |
| Латиница | Space Grotesk | Instrument Serif | Archivo (900) |
| Грузинский | Noto Sans Georgian | Noto Serif Georgian | Noto Sans Georgian |
| Палитра | `#FAF7F2` / `#191713` / `#3F7D4E` | `#F4ECDD` / `#2C1E12` / `#B4552D` | `#F3EFE4` / `#17130C` / `#F04E23` / `#FFC531` |

Все шрифты — Google Fonts, есть латиница и грузинский.

## Состав

- `*.dc.html` — артборды холста: на каждое направление лист логотипа
  (лого + монограмма PWA/Telegram/favicon + одноцветные версии) и четыре
  шаблона баннеров: 1080×1080 (лента), 1080×1920 (stories), 1280×720
  (Telegram), A6 397×559 px @ 96 dpi (печать).
- `canvas.json` — раскладка артбордов на холсте.
- `../logos/*.svg` — знаки отдельными файлами; `-mono` версии красятся
  через `currentColor` (для печати и поверх фото).
